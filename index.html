04 Projects

Data projects I've built end to end.

A couple of the dashboards I've shipped, from raw data to interactive reporting.

Excel · Power BI
Student Performance Dashboard

An interactive Power BI dashboard integrating Excel data models to track student academic performance and automate KPI tracking.

ProblemAcademic performance was tracked manually across scattered spreadsheets, making trends hard to spot.
ApproachModeled the data in Excel, then built a connected Power BI dashboard with automated KPI tracking.
ResultA single interactive view of academic KPIs, updated without manual recalculation.
ExcelPower BIData ModelingKPI Tracking
Raw academic records were consolidated and cleaned in Excel, then structured into a data model suitable for Power BI. The dashboard surfaces average scores, pass rates and enrollment trends, with KPI cards that recalculate automatically as new data is added — replacing what was previously a manual, spreadsheet-by-spreadsheet review process.
Microsoft Excel
Sales Data Tracker

An automated monthly sales tracking system using dynamic formulas, conditional formatting and summary Pivot Tables to monitor revenue without manual calculation.

ProblemMonthly revenue was recalculated by hand every cycle, which was slow and error-prone.
ApproachBuilt dynamic formulas and conditional formatting on top of a Pivot Table summary layer.
ResultRevenue and top-product trends update automatically as new sales rows are added.
ExcelPivot TablesConditional FormattingDynamic Formulas
Sales entries are fed into a structured Excel table, where dynamic formulas calculate running monthly totals and conditional formatting flags under- or over-performing periods at a glance. A Pivot Table layer summarizes revenue by product, removing the need for manual monthly recalculation.
